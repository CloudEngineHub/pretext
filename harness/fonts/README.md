The web fonts the harness serves to cases that name them in `fontFixtures`. Amiri, Noto Naskh Arabic, Noto Nastaliq Urdu and Shantell Sans come unchanged from the removed wrapping suite; Roboto and Inter are the real-usage sample's Latin web fonts, at the shares in `harness/sets/weights.json`. Each license sits beside its font: the SIL Open Font License 1.1, and Apache 2.0 for Roboto.

The environment key hashes each file with its family and weight, so changing one means recording every case again. (The old suite's maintained rows used installed fonts instead of its checked-in files, so a macOS update could move them.) Installed fonts such as Arial stay installed all the same: served copies changed Safari's results once, before 2026-09-05, and no numbers were kept ([RESEARCH.md](../../RESEARCH.md), Dead Ends).
