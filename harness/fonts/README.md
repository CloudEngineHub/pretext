The web fonts the harness serves to cases that name them in `fontFixtures`. Amiri, Noto Naskh Arabic, Noto Nastaliq Urdu and Shantell Sans come unchanged from the removed wrapping suite; Roboto and Inter are the real-usage sample's Latin web fonts, at the shares in `harness/sets/weights.json`. Each license sits beside its font: the SIL Open Font License 1.1, and Apache 2.0 for Roboto.

The environment key hashes each file with its family and weight, so changing one means recording every case again. Installed fonts such as Arial stay installed: served copies changed Safari's results once, in an investigation whose date and numbers weren't kept ([RESEARCH.md](../../RESEARCH.md), Dead Ends).
